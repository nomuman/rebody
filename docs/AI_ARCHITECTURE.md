# Re:Body AIコーチ

## 役割

AIコーチは、筋トレの種目を新しく作る機能ではありません。今日の状態と最近の実行履歴から、自由時間の前に一歩を始めやすくする短い気づきを返します。

既存の安全なメニュー選択はiOS側で行います。AIがメニューや負荷を勝手に変更しないため、痛みへの対応と運動内容を予測可能に保てます。

## 送信する情報

- 使える時間
- 疲れ具合
- 痛み・違和感の状態
- 今日の目的
- 中断される可能性
- 提案中のメニューID
- 最近の完了記録の種類、時間、何日前か

氏名、メールアドレス、写真、自由入力、位置情報は送信しません。痛みがある場合はOpenAIへ送信せず、アプリ内の安全メッセージを表示します。

## 処理の流れ

1. iOSアプリがFirebase Authenticationの匿名ログインを確認する
2. Firebase Functionsが入力値を許可された列挙値と範囲に絞る
3. 1ユーザー1日3回までの利用上限を確認する
4. FunctionsからOpenAI Responses APIへ短い日本語メッセージを依頼する
5. 生成結果を保存せず、iOSへ返す
6. 通信失敗、キー未設定、上限到達時はローカル提案へ戻る

## 本番設定

OpenAIを有効にするには、FirebaseプロジェクトでSecret Managerを有効にし、`OPENAI_API_KEY`をSecretとして登録してからFunctionsをデプロイします。モデルは`OPENAI_MODEL`で変更でき、未指定時は`gpt-5.6-luna`を使います。

APIキーはiOSアプリ、GitHub、Functionsの`.env`、ログに置きません。現時点のリポジトリとFirebase Secretには実キーを含めていないため、キー未設定のFunctionsはローカル提案を返します。実キーを登録するまで、AIコーチの表示はこのフォールバックになります。

## 削除

アプリのデータ削除操作では、匿名ユーザー、運動記録、AIコーチ利用回数の記録を削除します。AIコーチの生成結果は保存しません。
